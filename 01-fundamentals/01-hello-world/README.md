1.What is Go?
    Go is an open-source, statically typed, and compiled programming language developed by Google

2.What is a Go package?
    package is a directory containing one or more Go source files that are complied together

3.What is package main?
    package main is a special declaration that tells the Go compiler to build an executable program rather than a shred library

4.What does import do?
    the import keyword is used to give a Go source file access to code written in other packages

5.What is the purpose of main()?
    the main() function is the absolute entry point of an executable program

6.What is the difference between go run and go build?
    1) go build compiles your code into a permanent, standlone executable file
    2) go run compiles and execute your code immediately as a temporary backend progress
